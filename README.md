# 小步

一个 390×844 设计基准的移动端习惯养成 Web App，使用 React、TypeScript、Vite 和原生 CSS 构建。

## 安装与运行

```bash
npm install
npm run dev
```

生产构建：`npm run build`。

## 页面结构

应用包含首页、习惯、日历和我的四个一级页面。每页由 44px 状态栏、96px 页面头部、620px 内容区和 84px 底部导航组成。Tab 切换不会刷新页面。

## 滚动规则

页面和 body 均不滚动。习惯页只允许习惯列表纵向滚动；日历页只允许选中日期的任务列表纵向滚动；推荐习惯和成就仅在各自模块内横向滚动。

## 数据存储

习惯、2026 年 7 月记录和成长状态通过 React state 管理，并自动同步到浏览器 `localStorage`。完成某个习惯时，只更新该习惯，同时更新 7 月 12 日记录与完成总次数。

## 接入真实后端

可将 `useLocalStorage` 替换为请求层与服务端状态方案：启动时获取用户、习惯和日历记录；完成操作使用单习惯更新接口；创建习惯使用新增接口；成功响应后更新本地状态，并为失败操作加入轻量重试提示。
